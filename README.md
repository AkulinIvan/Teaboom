# Карточка товара «Ананасовый улун» — Teaboom.ru

Тестовое задание для позиции **HTML / Frontend-верстальщик**.

## 🔗 Демо

- **GitHub Pages:** `https://github.com/AkulinIvan/Teaboom/`
- **Локально:** откройте `index.html` в браузере — сборка не требуется.

## 📦 Стек

- HTML5 (семантическая разметка, Schema.org)
- SCSS → CSS3
- Vanilla JavaScript (ES2015+)
- CSS Grid + Flexbox

## 🚀 Запуск

```bash
# Открыть index.html в браузере — этого достаточно.
# Если хотите редактировать SCSS:
npm install
npm run build      # однократная сборка
npm run watch      # режим наблюдения
